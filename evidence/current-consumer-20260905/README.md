The verifier uses Python's standard library and optional read-only Git raw-blob hashing. It does
not run archived scripts, install dependencies, regenerate receipts or assert historical checks
still pass on changed source. See [manifest](manifest.json.txt), [raw copy map](copy-map.json.txt)
and [operator-only inventory](operator-only.json.txt). Repeated exact originals may map to one
identical payload; provenance is not collapsed into a new result.

Historical text is deliberately inert (`.txt`), including old scripts, tests, Markdown and JSON;
actual PNG/MP4/WebM files remain native media. The narrow packet `.gitattributes` preserves raw bytes.
The map discloses unshipped raw DOM, repeated full Git/process inventories and large served assets
already represented by repository/build hashes. Their original locations are operator references,
not promised portable paths. The original full manifests remain evidence of operator custody only;
the portable manifest certifies the actual copied subset.

Because raw DOM is omitted, a fresh recipient cannot reconstruct arbitrary hidden attributes,
scripts or full DOM, or replay the exact old browser session from PNGs and structured state alone.
